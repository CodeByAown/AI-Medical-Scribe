Workflow

One encounter in. An editable documentation draft out.

The product is intentionally narrow: capture the conversation, shape the draft, preserve clinician control, and make export into existing journal workflows straightforward.

01

Record once

Start with a single, native recorder surface on iPhone. No cluttered workspace, no setup wall before the visit, no need to choose between cloud and local until the recording is done.

02

Draft in the right lane

Stay fully local with Whisper ONNX on your CPU and Ollama for notes, or use cloud APIs (OpenAI, Anthropic, Gemini) for higher quality note generation.

03

Review before sign-off

Edit the note by hand, inspect previous versions, reopen earlier encounters, and export editable journal text or FHIR-compatible payloads without pretending the draft is final.

Privacy architecture

Built for healthcare constraints, not demo theater.

Server mode (recommended)

Audio is transcribed locally on your server with Whisper ONNX — no audio leaves your machine. The transcript is then sent to OpenAI (or Anthropic/Gemini) to generate the structured note.

  • Whisper ONNX runs on your CPU — zero audio sent to cloud
  • Only the text transcript reaches OpenAI for note generation
  • PHI redaction strips SSN, phone, DOB, email before any cloud call

Fully local mode

Install Ollama locally and pull any compatible model to run the entire pipeline on your own machine with zero internet required after setup.

  • Whisper ONNX for transcription (CPU)
  • Ollama + any local LLM for note generation
  • 100% offline — no API keys needed

Outputs

English-first, multilingual by design.

Neural Hub defaults to English SOAP notes but supports any language Whisper can transcribe. Switch language in the Advanced panel — Swedish, Spanish, French, German, and more all work.

Editable note draft

History and versions

Saved encounters, editable drafts, revision timelines, and visible recovery when a note changes.
